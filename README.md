# Lykios Campus

LMS propio de Lykios Academy. Paquete RC5 preparado para Vercel serverless.

- Web oficial: https://www.lykiosacademy.com/
- Campus previsto: https://campus.lykiosacademy.com/
- Datos: PostgreSQL (Neon recomendado para empezar)
- Recursos privados: Vercel Blob
- Pagos: Stripe, activación por webhook firmado

Lee `DEPLOY-VERCEL.md` antes de importar el proyecto.
